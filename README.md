# 抖音运营工作台

给独立创作者、运营同事和小型内容团队用的本地工作台。每天打开它，可以回答三个问题：**今天先处理哪件事？哪位同行的哪种做法值得学？下一条作品要改什么，什么时候看结果？**

例如，一条生活科普视频发出 24 小时后，5 秒留存率只有 30.0%，同系列此前四条作品的中位数是 52.5%。工作台会把作品、对照数和两组数值列在一起，提醒编辑检查开头。你可以把“第一镜就让观众看到实验”写进下一条简报，发布后回到同一时间窗口验证。下文用这个内置案例演示。

## 第一次使用

| 想做什么 | 怎么打开 | 能做什么 |
| --- | --- | --- |
| 先看一眼 | 下载 ZIP，完整解压，在电脑上双击 **快速预览.html** | 离线浏览八个页面、查看演示诊断和实验，无需安装 Python |
| 亲手走一遍 | 在解压目录执行 `python3 app.py serve --demo --open` | 在独立演示库中编辑简报、录入观众问题、试做实验 |
| 运营自己的账号 | macOS 双击 **启动工作台.command**，Windows 双击 **启动工作台.bat** | 在「数据接入」填写定位、导入作品数据，按自己的关键词开始找同行 |

上方版本包内的 macOS 启动器带有执行权限。若使用 GitHub 自动生成的源码 ZIP 或 Git 克隆，可直接运行以下命令；要双击启动器，也可以先在项目目录执行 `chmod +x 启动工作台.command`。

基础工作台要求 **Python 3.9+**，仅使用标准库。使用 Git 的读者可直接运行：

```sh
git clone https://github.com/demonlee0727-glitch/douyin-operator.git
cd douyin-operator
python3 app.py serve --demo --open
```

Windows 安装 Python 后，可将命令中的 `python3` 换成 `py -3`。浏览器会打开 `http://127.0.0.1:8765`。启动窗口保持开启，按 **Ctrl+C** 停止。体验后重新运行 `python3 app.py serve --open` 即可切换到正式账号，演示记录保存在独立目录。

## 怎样读首页的仪表盘

打开「今日工作」，中央旋钮显示未来七天的排期覆盖率。例如每周能做 3 条、已排 1 条时，读数为 33%。点下方的「反馈处理」可查看已处理反馈占全部反馈的比例。右侧折线按日期展示排期条数，点「导入作品快照」进入数据接入页面。

打开「账号诊断」，旋钮显示最近一篇作品采用快照的 5 秒留存率或完播率。左侧同时列出历史中位数和可比作品数；右侧趋势按作品发布时间排列，具体观察窗口见作品明细。读数 `—` 表示缺少该项数据，`0%` 表示已记录的零值。

## 跟着演示完成一次判断

### 1. 从一条作品找到一个值得测试的改动

打开「账号诊断」，找到 **演示 · 纸袋提手的折角**。它属于“生活科普 / 自然”分组，有四条更早作品都记录了发布后 24 小时的数据。5 秒留存率由历史中位数 52.5% 降到本篇的 30.0%，相差 **22.5 个百分点**。页面给出的动作是检查第一句话和关键画面。可以保留选题、时长和中段结构，下一期只改变首镜，再看同一指标。

![账号诊断实机截图：本篇 5 秒留存率 30%，左侧列出 52.5% 历史中位数及 4 条对照作品](docs/images/diagnosis.png?v=0.2.0)

自己的账号刚开始积累数据时，页面可能显示“补齐可比样本”。请先补录至少三条更早作品的同窗口数据，并填写系列和流量类型。仅凭昨天播放少，很难决定应该改开头还是改选题。

### 2. 从同行原作做一份自己的简报

在「同行雷达」点击作品标题查看原作。内置样本之一概述了作者“这不科学啊”把课本里的覆杯实验放大的做法。现有记录能支持的观察是标题将熟悉的实验和尺度变化放在一起。若要研究首镜和剪辑，需要观看原作，用“记录原作证据”保存时间点、具体动作和手法。有可使用的字幕时，也可以点“按字幕自动拆解”。

选择“借用手法，制作原创简报”，填写自己的问题和演示方法。例如把观众关于杯壁水珠的提问改成“同一杯冰水，换个杯子为什么没有水珠？”，让观众先看普通玻璃杯与保温杯并排，再给出解释。保存后到「内容排期」确认日期和制作阶段。

![同行雷达实机截图：查看作者已归档的作品、标题观察和原创简报入口](docs/images/peer-to-experiment.png?v=0.2.0)

### 3. 发布前定目标，发布后回填

在「增长实验」点“登记单变量实验”，填写唯一改动、目标作品 ID、系列、流量类型、指标与窗口。演示中的下一条作品用五条历史作品作对照，基线为 **52.0%**；设定相对提升 **10%**，目标便是 **57.2%**。新增的第五条历史作品解释了这里的基线为何与上一个案例不同。发布后导入与目标 ID 一致的 24 小时快照，页面会显示是否达到目标。

![增长实验实机截图：历史基线为 52.0%，目标为 57.2%，正在等待新作品的观察窗口](docs/images/growth-experiment.jpg?v=0.2.0)

## 接入自己的账号

1. 打开正式工作台，在「数据接入 → 账号定位」修改名称、受众、栏目承诺、关键词和周产能。
2. 在「作品数据 → 导入 CSV」选择文件或粘贴表格，点击“校验并导入”。也可把逐作品表格放入 `data/inbox/`。观察时间填写后台数据的实际截止时刻。
3. 在「同行雷达」使用关键词入口或“添加或校正同行线索”录入作品。需要定时检索时，按下表配置索引或官方搜索来源。
4. 在「数据接入」可开启自动排期。工作台按真实观众需求和近期表现信号填补未来七天的空档，生成的标题、日期、简报均可编辑。实际发布、公开回复和投放在抖音创作者中心完成。

### 常用命令

同一时间只开一个服务。端口被其他应用占用时可指定 `--port 8766`。正式数据默认保存在本目录的 data/；可通过 `--data /完整路径/我的账号` 分开运营不同账号。不要在两个同时运行的进程里对同一账号手动同步。演示模式使用独立的 data-demo/。

~~~sh
python3 app.py serve --demo --open
python3 app.py sync
python3 app.py report --out 本周运营复盘.html
python3 app.py state
~~~

快照报告可离线翻页，打印时导出当前页。报告包含当前账号的数据及输入过的文字，请根据接收人选择分享范围。

## 数据如何更新

| 来源 | 配置 | 更新方式与实际覆盖 |
| --- | --- | --- |
| 创作者中心导出 / 人工快照 | 无需密钥 | 运行期间每 30 秒检查 inbox，或在页面即时导入 CSV。表格需有统计截止时间；网页导入时也可填写整表观察时间。 |
| 同行网页索引 | `BRAVE_SEARCH_API_KEY` | 每 15 分钟轮换一个查询，轮流找主页和作品。查询来自账号关键词、近期作品系列、已归档作者。公开网页有索引延迟；没有作者身份时保留“作者待核对”。 |
| 抖音官方视频搜索 | `DY_SEARCH_TOKEN`、`DY_DEVICE_ID` | 需应用已获 `aweme.dy.video_search` 权限及真实设备标识。每轮按一个词取最近七天中最多十条，保存原作链接、作者和返回的文字。桌面工作台不会自行获得内测资格。 |
| 官方经营授权作品统计 | `DY_BUSINESS_TOKEN`、`DY_OPEN_ID`，配置 data/tracked.csv | 已获 `ma.item.data_bc` 能力并绑定的企业应用可用。每六小时轮询一批最多十条指定作品。平台一般次日上午刷新，仅返回近 30 天作品。采集时间无法代替统计截止时间，这批记录不进入固定年龄实验对照。 |
| Codex 辅助搜同行 | 在此项目中直接描述目标 | Codex 可按 AGENTS.md 读取当前定位、搜索公开抖音页，把已核对的出处写入 inbox。此方式在对话执行时更新，无需购买搜索 API。 |
| 深度文字拆解（可选） | `OPENAI_API_KEY`、`OPERATOR_MODEL` | 在具体作品卡主动选择模型拆解；只发送该作品标题和输入的文字。选择支持 Chat Completions JSON 输出的模型。只接受可以回到输入逐字核验的短引。未配置时使用本地文字规则。 |

在启动工作台的同一个终端设置环境变量。请不要把令牌发在对话里或写进待分享的项目包。以下是 macOS / Linux 示例；Windows PowerShell 使用 `$env:变量名="值"` 后从同一窗口运行 `py -3 app.py serve --open`。接口凭证到期后用自己已有授权应用更新它，工作台保留本地采集历史。

~~~sh
export BRAVE_SEARCH_API_KEY="自己的搜索服务密钥"
python3 app.py serve --open
~~~

“立即检查”运行一轮文件及已配置来源。上游限流、权限不足、凭证失效会记录原因并退避。启用外部搜索会向服务发送账号定位中的关键词、系列名称和已归档作者名称，请使用可公开的搜索词。模型和搜索服务按各自账户计费。

## 导入自己的数据

从创作者中心取得你有权使用的导出数据，可按 [CSV 字段模板](examples/metrics.csv) 改列名。文件夹支持 UTF-8 / GB18030 CSV，网页文件选择器适用 UTF-8。XLSX 文件放入 inbox，安装可选依赖 `python3 -m pip install openpyxl`，第一张活动表的首行须为表头。图表汇总行、合并标题行请先整理为逐作品记录。表格的长作品 ID 应存为文本，保留全部位数。

| 字段 | 填写方式 |
| --- | --- |
| 作品ID、作品标题、发布时间、观察时间 | ID 应保持稳定，也可用完整视频链接。时间如 2026-11-27 18:00，默认北京时间。观察时间填写数据实际截止时刻。 |
| 系列、流量类型 | 自定义系列；同题材不同片长建议分组。流量填自然、付费、混合或未知。 |
| 播放量、点赞、评论、分享、收藏、新增关注、完播率、5秒留存率 | 至少提供一项。留空代表未知，零代表已观测为零。百分比填 25% 或 0.25。互动次数填未四舍五入的整数。 |

同一作品同一观察时刻只保留一条快照；补充列会合并。整表遇到坏行会回滚并告知行号。内容相同的文件会跳过。将授权统计示例 [指定作品模板](examples/tracked.csv) 复制为 data/tracked.csv，逐行填作品内部标识、开放平台 item_id（保留原值）、标题、发布时间、系列和流量类型。网页作品 ID 与开放平台 item_id 的获取口径可能不同，请以授权应用实际返回的标识为准。

同行批量导入支持 JSON 数组，参考 [同行样本 JSON](examples/public-references.json)。每条至少包含一个抖音作品/主页完整链接和标题，可增加 author、keyword、summary、caption、source。住宅位置、手机号和原始登录信息不需要录入。

## 一次完整的运营循环

- **晨检**。打开「今日工作」确认数据时效、排期缺口和事实质疑。最近作品的每次采集、采用的对照快照和历史中位数均可追溯。
- **找同行**。从同受众、同问题或同表现形式开始。打开原作核对，分清单条线索与有重复方法的作者。初始附两位科普作者、三条公开历史作品，作为观察起点。
- **拆方法**。记录维度、时间点或标题位置、可观察事实和手法。相同手法出现在同作者两条不同作品后，才进入“重复方法”。看完原作后可补充镜头动作、音效与评论。用自己的实验检验迁移效果。
- **做内容**。从作品或观众问题生成原创简报，明确“哪里做相同、哪里做不同”。在排期中管理选题、制作、待发布、已发布、已复盘。发布和公开回复通过创作者中心完成，排期页留存实际作品 ID。
- **复盘**。以 2 小时（±0.5）、24 小时（±3）、72 小时（±6）、7 天（±12）为观察窗口。每个系列、流量类别及指标至少 3 条历史对照才给出相对表现判断。关注率与深度互动口径见[运营值班手册](OPERATIONS.md)。
- **沉淀经验**。在「增长实验」预先登记唯一变量、目标作品和提升阈值。历史对照冻结；真实结果到来后显示达标情况。品牌合作、投流及事实纠错同样有交付物与复盘方法，见「运营手册」。
